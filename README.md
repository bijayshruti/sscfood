# 🍽️ Tasty Food — Staff Selection Commission

Control Room Meal Ordering System — Streamlit + Supabase.

## Features

- **Members**: place meal orders (Breakfast / Lunch / Snacks), track status
- **Admin**: confirm / reject / correct orders, manual entry, rates, misc expenses, expenditure reports, WhatsApp reminders, menu management, data export/backup
